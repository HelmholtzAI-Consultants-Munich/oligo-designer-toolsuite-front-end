# Oligo Designer Toolsuite Cloud

This site provides comprehensive documentation for the Oligo Designer Toolsuite web application. The documentation is organized into two main sections:

## For Users

The majority of this documentation is designed for **users of the web application**. Here you will find:

- **Getting Started** guides for new users
- **Pipeline Documentation** with detailed descriptions of each supported pipeline (MERFISH, SeqFISH, Scrinshot, OligoSeq, and Genomic Region Generator)
- **User Guides** covering authentication, run management, and artifact handling
- **Usage Instructions** explaining how to interact with the system and run oligo design experiments

Whether you are a new user looking to get started or a researcher aiming to understand the pipeline options, these guides will walk you through every major feature and usage scenario.

## For Developers

The **Development** section contains technical documentation for **developers working on the codebase**. This section covers:

- **Development Setup** including Docker configuration and IDE setup
- **Testing** strategies and how to run tests
- **Monitoring** infrastructure and observability
- **Error Handling** implementation details
- **Caching** mechanisms and optimization strategies
- **Architecture** and technical implementation details

If you are a developer interested in extending the platform, contributing code, or understanding the technical implementation, refer to the Development section in the sidebar.
