# Oligo Designer Toolsuite — Frontend
This site provides the comprehensive documentation for the frontend of the Oligo Designer Toolsuite. Here, you will find in-depth explanations of the platform’s architecture, user interface, and workflow. This documentation covers all aspects of the frontend, including how users interact with the system, detailed descriptions of each supported pipeline (such as MERFISH, SeqFISH, Scrinshot, and Genomic Region Generator), as well as user authentication, run management, and artifact handling.

Whether you are a new user looking to get started, a researcher aiming to understand the pipeline options, or a developer interested in extending the platform, this guide will walk you through every major feature and usage scenario. Use the sidebar to explore installation steps, usage guides, technical details, and best practices for managing and running oligo design experiments through the web application.
