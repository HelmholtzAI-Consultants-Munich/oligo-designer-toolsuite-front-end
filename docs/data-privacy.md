# Data Privacy Statement (odt-dev)

This service is operated by Yarkın Eren for development and testing purposes of the Oligo Designer Toolsuite (ODT).

It uses the Helmholtz Authentication and Authorization Infrastructure (AAI) for user login.

## Purpose of Data Processing

Authentication of users for testing and demonstration of ODT functionality.

## Processed Data

Basic user identity data (name, email, organization, persistent ID) provided by Helmholtz AAI.

## Legal Basis

Legitimate interest (Art. 6(1)(f) GDPR) in securing access to the test system.

## Data Retention

No personal data is permanently stored; data is used only for session validation.
